# Kostanyan Learning Center

Статический сайт: главная страница, галерея и блог. Русская версия находится в `/ru`, английская — в `/en`. Корневые страницы сохранены как прежняя версия на время проверки и переноса.

## Просмотр
Распакуйте архив и откройте index.html в браузере. Сохраняйте структуру папок: фотографии находятся в assets/.

Для локального сервера при установленном Python выполните из папки проекта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8000/ .

## Содержимое
- ru/ — русские страницы сайта
- en/ — английские страницы сайта и сценарий отсутствующего перевода
- index.html — главная страница
- gallery.html — галерея
- styles.css — оформление
- script.js — три языка, переключение форматов, проверка формы
- assets/ — три локальные фотографии
- PHOTO_CREDITS.md — источники фотографий

Форма отправляет заявки владельцу через серверный маршрут `/api/telegram`. Для публикации в Vercel нужно задать серверные переменные окружения `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`, а затем заново развернуть проект. Значения секретов нельзя добавлять в репозиторий или клиентский JavaScript.

Фото иллюстративные, не из самого центра. Контактные ссылки в плавающей кнопке нужно заменить реальными ссылками владельца после их получения.
